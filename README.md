# NETVIEW3D (NetVisio 3D Studio)

Aplicación web interactiva tipo **Visio en 3D** para diagramación de arquitectura de Data Center, Redes, Cómputo HCI, Almacenamiento SAN/NVMe y Seguridad Perimetral, con rotación libre en los **3 ejes (`X`, `Y`, `Z`)**.

## Características principales

- **Rotación en 3 Ejes (`X`, `Y`, `Z`)**:
  - Rotación orbital completa del diagrama y controles dedicados para **Pitch (`X`)**, **Yaw (`Y`)** y **Roll (`Z`)**.
  - Gizmo interactivo (`W` Mover, `E` Rotar en 3 ejes, `R` Escalar) para cualquier objeto del diagrama.
- **Librería de Equipos 3D**:
  - **Racks & Enclosures**: Gabinete Rack Enterprise 42U (con auto-encaje por unidad `U`), **HPE Synergy 12000 Frame (10U)**.
  - **Cómputo & HCI**: **Nutanix NX-3060-G8 (4-Node)**, **Nutanix NX-8155-G8**, **HPE ProLiant DL380 Gen11 (2U)**, **HPE ProLiant DL360 Gen11 (1U)**, **Dell PowerEdge R760 (2U)**.
  - **Storage All-Flash**: **HPE Alletra 9000 (4U)**, **HPE Alletra 6000 (2U)**, **Pure Storage FlashArray//X90 (3U)**, **Pure Storage FlashBlade//S (5U)**.
  - **Redes Cisco**: **Cisco Nexus 9508 Chassis (13U)**, **Cisco Catalyst 9410R Chassis (13U)**, **Cisco Catalyst 9300-48P (48 puertos)**, **Cisco Catalyst 9300-24T (24 puertos)**, **Cisco Nexus 93180YC-FX3**.
  - **Seguridad Fortinet**: **FortiGate 1800F (2U)**, **FortiGate 600F (1U)**, **FortiGate 200F (1U)**, **FortiGate 3000F (2U)**.
- **Cableado 3D Inteligente**:
  - Enrutamiento **Ortogonal 3D (Visio Manhattan)**, **Bandeja Aérea Superior** y **Curva Directa** con animación de tráfico en tiempo real.
  - Exportación/Importación de proyectos en **JSON**, captura **PNG** e inventario **BOM (CSV)**.
